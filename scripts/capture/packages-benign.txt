# Benign npm capture list -- widely used, actively maintained packages.
#
#   sudo bash scripts/capture/capture.sh \
#     --list scripts/capture/packages-benign.txt --label 0 --out captures/benign
#
# Why this list exists
# --------------------
# The current benign class is 14 real libraries plus 2 synthetic fixtures,
# while the malicious class is 6 synthetic fixtures built from one template.
# Any feature that separates "written from Aniruddha's template" from "real
# library" therefore reads as a malware signal. os_user_dir demonstrates the
# problem: Cohen's d = 2.70 off a 3% difference, because every benign session
# reads 865 or 879 user-dir paths and every malicious one reads 904-913. The
# model is learning which template produced the package.
#
# Replacing the benign class with a few hundred real, varied packages removes
# that confound. Variety is the point -- a corpus of 200 tiny utility libraries
# would just trade one narrow template for another -- so this list deliberately
# spans dependency-free one-liners, mid-size libraries, and packages that pull
# large dependency trees.
#
# Selection notes
# ---------------
# Packages whose install step downloads a prebuilt binary from somewhere other
# than the npm registry are excluded: puppeteer, playwright, electron, cypress,
# node-sass, canvas, sharp. Under the capture firewall those downloads hit the
# sinkhole and the install fails, producing a session that measures a failed
# download rather than a real install.
#
# Lines beginning with # are ignored, as is anything after a # on a line.
